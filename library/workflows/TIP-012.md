## What It Does

Implements a complete virtual game studio as a Claude Code plugin: 48 AI agents covering every studio role (lead programmer, game designer, audio engineer, QA tester, producer, etc.) and 36 skills that coordinate them following a real studio pipeline. Agents hand off tasks between departments — design to programming to art to QA — via structured workflows.

## How to Use It

1. Clone the repo and load it as a Claude Code plugin or global skill set
2. Invoke studio roles by name: "ask the game designer to spec out the level progression"
3. Follow the workflow skills to move tasks through departments

## Security Notes

Pure shell scripts and markdown agent definitions. No external API calls. Review agent prompts to understand the scope of actions each role can take.

## Alternatives

Individual Claude Code agents built per task, or the SuperClaude framework (TIP-041) for a more general approach.
