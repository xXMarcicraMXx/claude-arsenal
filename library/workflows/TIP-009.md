## What It Does

A Claude Code plugin that enables multi-agent parallelism: Claude orchestrates the task, dispatches subtasks to multiple Codex (OpenAI) agents running in parallel, collects their outputs, and merges/reviews the combined result. Useful for large codebases where parallel code generation speeds up work.

## How to Use It

1. Clone the repo and load it as a Claude Code plugin
2. Set your OpenAI API key in the environment
3. Trigger parallel delegation via the provided slash commands

## Security Notes

Requires OpenAI API key — requests are sent to OpenAI servers. Review the plugin's shell scripts before use to confirm no data is sent elsewhere.

## Alternatives

Claude Code's native subagent system (Agent tool) without requiring OpenAI keys.
