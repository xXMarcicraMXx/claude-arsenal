## What It Does

Implements the Model Context Protocol for Unity Editor, exposing Unity's scene hierarchy, assets, and editor commands as MCP tools. Lets Claude Code (and Cursor, Codex, Windsurf) inspect GameObjects, run editor scripts, create prefabs, and debug issues — all through natural language in the IDE.

## How to Use It

1. Install the Unity package from the repo into your Unity project
2. Start the MCP server (Node.js or Python bridge included)
3. Add the MCP server to Claude Code's `settings.json` under `mcpServers`
4. Ask Claude to inspect or modify your Unity scene

## Security Notes

The MCP server runs locally and connects to your Unity Editor via its API. Does not send project data externally. Review the C# package source before installing into production Unity projects.

## Alternatives

Manual scripting via Unity's C# API or Unity's built-in AI tools (Unity Muse).
