## What It Does

PAL (Provider Abstraction Layer) MCP server enables Claude Code, Gemini CLI, Codex CLI, and IDE clients to orchestrate multiple AI models within a single prompt. Includes a CLI-to-CLI bridge (clink) that lets one CLI spawn isolated subagent instances of another CLI for context-isolated tasks like code review.

## How to Use It

1. Clone the repo and follow the MCP server setup instructions
2. Add PAL to your Claude Code MCP config
3. Use `clink` to spawn cross-CLI subagents: `clink with codex codereviewer to audit auth module`
4. Use consensus tool for multi-model decisions

## Security Notes

Requires API keys for each model provider you want to use. Makes network calls to multiple AI provider APIs. No license assertion in metadata. Python-based. 11K+ stars indicates community trust.

## Alternatives

Using individual MCP servers for each model provider
