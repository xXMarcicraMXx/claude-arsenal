## What It Does

A full SEO analysis skill for Claude Code covering technical SEO, on-page analysis, content quality (E-E-A-T), schema markup, image optimization, sitemap architecture, AI search optimization (GEO), and strategic planning. Uses 7 parallel subagents for site audits. Includes DataForSEO MCP integration.

## How to Use It

1. Clone and install: `git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git && bash claude-seo/install.sh`
2. Windows: `git clone --depth 1 https://github.com/AgriciDaniel/claude-seo.git && powershell -ExecutionPolicy Bypass -File claude-seo\install.ps1`
3. Run commands: `/seo audit https://example.com`, `/seo page https://example.com/about`, `/seo schema https://example.com`

## Security Notes

Installs via bash/PowerShell script. Requires Python. Uses subagents that make web requests to analyze target URLs. Review install.sh before running. MIT licensed with CI.

## Alternatives

Manual SEO audits, third-party SEO tools outside Claude Code
