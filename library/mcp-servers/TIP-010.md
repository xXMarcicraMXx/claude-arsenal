## What It Does

Implements an MCP server that wraps the Home Assistant REST API, exposing entities, automations, scripts, and configuration as MCP tools. Claude Code can then create automations, modify Lovelace dashboards, debug YAML configs, and deploy changes directly to your HA instance through natural language commands.

## How to Use It

1. Install the Python MCP server and configure your HA URL and long-lived token
2. Add to Claude Code's `mcpServers` configuration
3. Ask Claude to "add a motion-triggered light automation" or "debug my heating script"

## Security Notes

Requires a Home Assistant long-lived API token with full access. The server communicates with your local HA instance. Treat the token as a secret — do not expose it in shared configs. Review automation changes before deploying.

## Alternatives

Home Assistant's built-in AI assist feature (more limited), or manual YAML editing.
