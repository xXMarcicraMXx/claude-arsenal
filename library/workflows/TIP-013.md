## What It Does

A TypeScript plugin from EveryInc (the company behind the Every.to writing platform) that encodes their internal compound engineering workflow for Claude Code. Provides structured agents, prompts, and coordination patterns used in real production software development. Compatible with Claude Code, Codex, and Windsurf.

## How to Use It

1. Install via npm or clone the repo
2. Load as a Claude Code plugin in your project's `.claude/` directory or via `CLAUDE.md`
3. Follow the plugin's workflow guides to adopt the compound engineering patterns

## Security Notes

TypeScript, runs locally. No external API calls beyond the AI provider. Actively maintained by a production engineering team. Review before adding to global Claude Code settings.

## Alternatives

Anthropic's official Claude Code docs on multi-agent patterns, or SuperClaude Framework (TIP-041).
