## What It Does

A universal Claude Code plugin that ships with a full set of agents, skills, hooks, and slash commands. Acts as a project scaffold: clone it, point Claude Code at it, and get a structured multi-agent workflow immediately. Built in Python with a modular architecture.

## How to Use It

1. Clone the repo into your project or as a global plugin
2. Load it via `CLAUDE.md` or the `.claude/` directory
3. Use the pre-defined agents and skills, or customize them for your stack

## Security Notes

Requires Python. The plugin runs local agents and uses hooks — review the agent definitions before deploying globally. No external API calls beyond Claude itself.

## Alternatives

Build your own `.claude/agents/` directory manually following the Claude Code docs.
