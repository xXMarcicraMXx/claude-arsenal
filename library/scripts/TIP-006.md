## What It Does

Adds Claude Code hooks that trigger shell audio playback when Claude finishes responding. Uses the OS-native audio player (afplay on macOS, PowerShell on Windows, paplay/aplay on Linux) so no external dependencies are needed. Configurable sound file and volume.

## How to Use It

1. Clone or download the repo
2. Copy the hook script to your project's `.claude/hooks/` directory
3. Add the hook to `.claude/settings.json` under `PostToolUse` or `Stop`
4. Configure the audio file path in the script

## Security Notes

Runs a shell command after each Claude response. The script executes a local audio file — no network calls. Review the hook script before adding it to global settings to ensure it only plays audio.

## Alternatives

Desktop notifications via `notify-send` (Linux) or `osascript` (macOS) as a lighter alternative.
