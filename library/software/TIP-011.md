## What It Does

A TypeScript desktop application (likely Electron or Tauri) that reads your Claude Code `.claude/agents/` configuration and renders it as an interactive org-chart. Supports drag-and-drop reorganization of agent hierarchies, skill assignment, and configuration editing — exporting back to the standard Claude Code format.

## How to Use It

1. Install via npm or download the release binary
2. Point it at your project's `.claude/` directory
3. Use the visual editor to configure agents, then export the config

## Security Notes

Reads and writes your local `.claude/` directory. No external API calls. Review the generated config files before use in production.

## Alternatives

Manual editing of `.claude/agents/*.md` files in any text editor.
