## What It Does

A self-learning system that hooks into Claude Code sessions to capture corrections, positive feedback, and preferences. Syncs learnings to CLAUDE.md and AGENTS.md for permanent memory. Also analyzes session history to discover repeating tasks and suggests reusable slash commands.

## How to Use It

1. Install via marketplace: `claude plugin marketplace add bayramannakov/claude-reflect`
2. Install plugin: `claude plugin install claude-reflect@claude-reflect-marketplace`
3. Restart Claude Code
4. Use `/reflect` to review and sync corrections to CLAUDE.md
5. Use `/reflect-skills` to discover workflow patterns from session history

## Security Notes

Installs as a Claude Code plugin. Requires Python 3.6+. Reads session history and modifies CLAUDE.md/AGENTS.md. MIT licensed with 160 passing tests.

## Alternatives

Manually updating CLAUDE.md with lessons learned (similar to tasks/lessons.md pattern)
